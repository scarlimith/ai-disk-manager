AI 磁盘管家 1.6 — 中文本地文件浏览、AI 内容盘点与批量清理

双击 AI磁盘管家.exe，无须另装 Python。界面使用 Python/Tk/ttk。
目标 Windows 10/11 x64，仅当前电脑实测；支持规则和窗口尺寸检查不代表兼容所有电脑、所有 AI 版本。

1. 文件清单
默认选择全部有盘符的本地磁盘，开始扫描后可随时停止；停止会保留局部结果。
“扫描设置”可添加目录、调整未知大文件阈值、关闭会话溯源。溯源读取受支持本地JSONL，耗时随记录体积增加。
网络盘和无盘符隐藏卷不自动遍历；链接不跟随。无法读取项与溯源错误均计数，不是零大小。
历史快照不代表当前状态，旧版会提示重新扫描；右键单项可重新扫描。
左侧固定九类：缓存与日志、环境与依赖、模型与权重、聊天与任务、项目与素材、生成成果、个人资料、待确认内容、系统与应用状态。
紧凑顶部显示容量摘要、地址、搜索与筛选。左侧有“所有文件”“可清理候选”“受保护资料”、九种分类和磁盘入口。
主表默认平铺清单，显示名称、清单、大小、删除建议、AI来源/证据和占已发现比例；较宽窗口增加所在位置。点击列标题排序，箭头说明方向。
容量条按内容分类或关联工具汇总，点击分组即可筛选；“查看全部”可查看完整分组列表。统计是全部已发现内容的逻辑大小，不等于可释放空间，也不随筛选、换页改变占比分母。
大小筛选支持 ≥1 GiB、≥100 MiB、<1 MiB；搜索多个词同时匹配，例如 codex 缓存，支持 "API 输出" 等短语和 *.gguf、image?.png 文件名通配符。
列表上方显示结果数量、总量和生效条件。“清除筛选”保留当前目录和跨页清理清单。空列表会引导开始扫描，无匹配时会提示清除筛选。
“显示列”或表头右键可以选择分类、保护状态、完整路径等列；列选择保存，并在主题或窗口变化后保留。“恢复自适应列”回到按宽度安排。
较短窗口将磁盘和 API登记/支持/引导/导出入口收进“磁盘目录”和“更多工具”菜单，保留九类内容浏览空间。
可切换“目录浏览”“类型树”“磁盘目录树”。类型树按分类和关联工具分组；磁盘目录树按真实路径分组。
点击磁盘或双击虚拟目录进入目录浏览。顶部地址栏显示当前位置；“←”返回上个浏览位置，“↑”返回上一级。
黄色虚拟目录是导航入口，统计只覆盖本次扫描已经发现的内容，不能勾选或删除，不代表完整文件系统清单。
类型/路径分组只导航，分组数量和大小为本页小计。每页最多200个实际文件项，虚拟节点不重复计量。
双击已识别的真实目录或点击“进入目录”，按需读取内部文件后进入浏览，小文件也可查看。不完整或停止时保留原目录项。
点击“详情”打开右侧面板，查看完整路径、生成者/修改者、证据、建议原因、删除影响及保护原因。
较窄窗口默认收起详情，仍可主动打开；大窗口选择文件可自动显示。多选时显示数量、合计大小和各项建议、保护原因。
右键可复制所选完整路径；打开位置、进入目录和重新扫描等单项操作应只选一项使用。
“预览文件内容”支持常见图片和文本/代码，文本最多前64 KiB；其他格式通过“打开文件位置”查看。链接不在程序内预览。
逻辑大小不等于可释放空间：硬链接、稀疏/压缩文件和回收站均影响实际占用。

2. 来源证据
已确认新增：本地执行记录确认新增写入，并有独立成功写入工具证据，才显示生成者。
已确认修改：只确认修改者，不把用户已有文件全部归为AI创建。
请求未确认：只有写入请求，未确认成功。
仅关联/目录线索：路径被引用、读取、工具返回或属于已知输出目录；不能证明逐文件作者。
人工登记：用户或导入日志声明，未独立核验生成者。
未知：没有足够证据。体积大或名字叫cache/output不代表AI垃圾。

3. API和自写脚本
侧栏“API 来源登记”：选择目录/文件，填写工具或脚本、API提供方、可选模型与用途。
可“仅登记”或“登记并扫描该路径”。登记目录内的小文件会纳入扫描，内容默认保护，缓存登记也不会自动解锁。
可导入 API来源登记示例.json 格式，先改为自己的实际路径和来源。
标准schema为 ai-disk-manager.provenance.v1；records可包含path/provider/tool/model/role/action/kind/evidence。
role：output/cache/runtime/project/input/model；action：declared/created/modified/referenced/downloaded。
缺失的未来输出目录需kind=directory。拒绝网络/设备、系统根、重解析路径和敏感声明字段。
不填写API密钥、提示词、请求或响应正文。来源识别不监听API请求、不访问账户、不读环境密钥或通过项目代码猜测来源。
用户主动预览时才读取所选文件的预览内容，不把预览内容当作AI作者证明。
未留存记录的任意客户端文件无法仅凭磁盘内容确定哪个AI生成；可人工登记，或让自己的脚本输出标准清单。

4. 多选、清理清单和保护审核
高亮选择表示当前查看/操作的文件；底部“待清理”表示已加入清理清单的文件，两者不同。默认不选任何删除项。
Ctrl点选追加/移除选择，Shift点选连续选择；“全选本页”只选择当前页实际文件项。
多选后“加入清理清单”或按空格，可处理项加入，仍受保护或禁止项跳过并显示数量；已选可处理项全部已加入时，空格将它们移出。
行内“清单”栏可单独加入/移出；右键也可将所选加入清单、从清单移除或预览删除。
清理清单跨页保留。“查看清单”显示完整路径、大小与建议，可多选“移除所选”；“清空”只清空清单，不删除文件。
行内建议包括关闭工具后可清理、建议清理、建议保留、按需卸载、待确认、禁止处理；详情说明原因与影响。
建议不会自动勾选。环境和模型优先通过所属工具卸载；生成物也可能是重要成果。
聊天、项目、模型、生成或修改成果、未知来源默认保护。确定不用时，选择文件并从详情或右键打开“审核保护…”。
单项需查看路径与影响后确认；多项打开逐项审核表，默认全部未勾选，显示完整路径和删除影响，只有主动勾选并确认的具体项允许进入预览。
审核本身不删除文件，也不自动加入清理清单。禁止项不能解除；单项已解锁时可通过审核操作恢复保护。
底部“预览并移入回收站”处理清理清单；“预览所选…”或Delete处理当前高亮项，进入同一个核对与预览流程。
直接处理所选时，遇到尚未允许处理的项就停止整个选择，显示具体原因；请先审核，或从选择中移除禁止项。
处理前核对路径、成员快照、保护规则和回收站容量，失败显示具体原因且整个批次停止。
旧快照或内容已变化时，右键重新扫描相关项，看新结果后重新选择。
预览必须主动勾选“我已查看清单和删除影响”，才能确认移入回收站。
核对失败时不执行；执行结果按项报告，无永久删除兜底。移入回收站后仍可能占用空间，清空后才释放，可从系统回收站恢复。
系统、凭据、数据库、应用状态、链接、统计不完整项与本工具资产禁止删除，不能解除。
工具保护精确到程序/源代码/报告/构建资产，同一“小工具”目录其他项目不会因此永久锁定。
处理元数据记录在 扫描报告/cleanup_audit.jsonl，不记录文件正文。

5. 支持和外观
支持列表列出17类目录/结构规则：Codex、Claude、Claude Code、Cursor、Windsurf/Codeium、GitHub Copilot、Continue、Aider、ChatGPT、Ollama、LM Studio、Hugging Face、ModelScope、ComfyUI、Stable Diffusion WebUI、Fooocus、共享依赖生态。
共享依赖也用于非AI项目，不能当AI专用垃圾。规则支持不等于所有版本和渠道实测。
写入溯源目前仅部分支持Codex/Claude Code本地JSONL；其他按路径/结构或人工登记显示。
无法保证云端聊天、浏览器缓存逐站点归属、任意API或未留存记录的全部文件自动识别。
支持与兼容页提供本机只读自检，不能承诺兼容所有电脑、操作系统、AI版本和磁盘配置。
侧栏主题支持亮色、暗色、跟随系统；使用引导可重开。导出CSV/JSON包含完整路径、来源证据、生成者/修改者、建议和影响。

6. 常用快捷键（文件列表获得焦点时）
Ctrl + 点选：追加/移除单项选择。
Shift + 点选：连续选择。
Ctrl + A：选择当前页实际文件项；不选择虚拟目录或分组。
Ctrl + C：复制所选完整路径。Ctrl + I：打开/收起详情。
空格：将所选可处理项加入清单；如果这些项都已加入，则移出。
Delete：预览删除当前所选项，不直接删除。
Esc：取消列表高亮选择，不清空清理清单。
Alt + ↑：上一级目录。Alt + ←：返回上一个浏览位置。
Ctrl + F：焦点移到搜索框。
双击目录：进入目录；双击文件：显示详情。

1.5 操作改进
选中受保护内容时，主要动作显示“审核保护…”，普通可处理项显示“预览所选…”。没有可处理项时，“加入清理清单”不可用；不会自动解除保护。
逐项保护审核中，点击名称仅查看，点击勾选列才批准。永久保护不能解除。
最终确认窗口改成表格和所选项详情，显示数量、合计逻辑大小、完整路径、建议与影响；确认勾选默认关闭。
“打开回收站”使用 Windows 系统回收站界面，需在那里手动检查或还原；程序没有内置恢复点管理。

1.6 主题画廊

点击左下角“主题…”打开画廊，点击预览图或主题按钮即可应用并保存；Tab 和空格也可选择主题，点击“完成”返回。
共有8套外观：亮色、暗色、Doro乐园、Doro夜游、薄荷庭院、奶油拿铁、午夜蓝、紫藤夜色，另提供“跟随系统”。
Doro主题带粉发、紫眼、白色短腿身体的Doro同人插画，在侧栏、页头和空列表引导中显示。主题素材随程序内置，无需下载。
切换只改变外观，保留已选文件、跨页清理清单、显示列和文件保护状态。不会替你勾选文件、解除保护或执行删除。
窄窗口侧栏保持足够宽度，以显示完整的分类、计数与主题入口。
