# 1.5.0 验证摘要

测试仅在开发电脑上进行。下面是已完成的检查，不代表兼容所有电脑、所有显示缩放或所有 AI 工具版本。

| 范围 | 本轮结果 |
| --- | --- |
| 回归 | 138 项，137 通过，1 因本机符号链接创建权限跳过，无失败 |
| 交互 | 实际 Tk 事件检查 Ctrl/Shift、空格、多选保持、跨页清单、来源/容量筛选、目录保持、空状态、列配置 |
| 保护 | 普通行浏览不批准，勾选列才批准；永久保护排除；选中受保护项直接进入审核 |
| 预览 | 表格选择能显示对应完整路径与影响，最终确认默认关闭；取消保留所有项 |
| 原生回收 | 只将两个自建微小缓存目录（17 + 34 字节）移入 Windows 回收站；其他测试文件保留 |
| 独立 EXE | 仅 EXE 初始目录，中文含空格路径；独立启动验证 1760×1180、1280×900、1060×720 × 亮暗两种主题 |
| API 样例 | 两个自建小文件共 43 字节，人工登记且默认保护；无需另装 Python |
| 本机兼容检查 | 独立 EXE 成功生成本机检查与 17 类规则生态清单，不执行删除 |
| 数据保持 | 原用户扫描报告、界面设置、来源登记指纹不变，零 Tk 回调异常 |

列菜单检查使用真实变量和命令，但模拟原生菜单弹出；打开回收站只校验调用，不自动操作系统回收站界面。窗口尺寸验证分别独立启动 EXE，避免测试脚本的原生菜单焦点、最小化状态影响截图。

产品演示图的容量和路径为模拟数据。51 字节回收测试不代表实际释放大量空间；程序没有完整树图、MFT 加速、模型去重或内置恢复管理。没有竞品性能实测、误删率统计、独立安全审计或“100% 安全”保证。
