# 支持范围与限制

版本：1.4.0。目标平台：Windows 10 / Windows 11 x64。只在当前开发电脑完成实测；其他机器、ARM、32 位 Windows、macOS 和 Linux 没有发行兼容性验证。

## 已实现的规则生态

| 生态 | 当前识别方式 |
| --- | --- |
| Codex | 目录/结构规则，部分本地 JSONL 写入证据 |
| Claude、Claude Code | 目录/结构规则；Claude Code 部分本地 JSONL 写入证据 |
| Cursor、Windsurf/Codeium、GitHub Copilot | 已知路径与结构规则 |
| Continue、Aider、ChatGPT | 已知路径与结构规则 |
| Ollama、LM Studio、Hugging Face、ModelScope | 模型/缓存等路径与结构规则 |
| ComfyUI、Stable Diffusion WebUI、Fooocus | 模型、输入/输出、项目等目录结构线索 |
| 共享依赖生态 | 依赖、环境、下载缓存等规则，也用于普通软件项目 |
| 用户的 API / 自写脚本 | 路径人工登记或标准清单导入；不是自动监听 API |

合计 17 类规则生态。目录属于某工具不证明每个文件由该 AI 生成；来源确认、关联、人工声明和未知会分别显示。支持列表表示规则已实现，不能代替每个产品版本、安装渠道和实际环境的验证。

## 扫描与容量

默认选择有盘符的本地固定/可移动磁盘；网络盘、隐藏卷和无盘符卷不自动遍历。文件系统链接和重解析点不跟随。无法访问项单独计数，不作为零容量。

扫描按目录遍历，未使用 NTFS MFT 快速索引；大盘、机械盘、依赖目录多或会话记录大时，可能需要较长时间。可以先扫描特定目录，或停止后查看局部结果。

历史快照和停止产生的局部结果会标记；统计不代表完整文件系统清单。显示逻辑大小，硬链接、压缩/稀疏文件以及回收站影响实际空间回收。移入回收站不等于马上释放空间。

## 处理限制

建议不会默认选中。聊天、项目、模型、生成或修改成果、未知内容默认保护；系统、凭据、数据库、应用状态、链接、统计不完整内容和工具自身资产禁止处理。

模型和环境优先通过其所属工具管理。处理缓存前应关闭相关任务，并核对影响；可能需要重下载或重建，也可能失去诊断日志。

删除仅通过 Windows 回收站，核验失败时停止，不提供永久删除兜底。恢复通过系统回收站完成；本版没有内置一键恢复管理器。清理清单容量不是已经释放容量。

## 尚未具备

- 任意云端聊天、所有 AI 工具/版本、所有 API 输出的完整自动归属。
- 无来源记录的文件逐项确定生成者或生成模型。
- 模型内容去重、Docker/WSL 虚拟盘压缩、常驻监控、进程结束或卸载管理。
- 扫描速度优于 WizTree 等工具的实测证据。
- 所有电脑、显示缩放、磁盘格式及权限配置的兼容保证。
